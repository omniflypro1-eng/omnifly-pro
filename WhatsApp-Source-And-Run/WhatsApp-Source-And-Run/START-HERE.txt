واتساب — السورس + نسخة التشغيل

Source = السورس المختصر: 13 ملفًا، مع شرح الدمج في README.md.
Run    = نسخة جاهزة للتشغيل المحلي على Windows x64، مع متطلباتها.

للتشغيل:
1. فك ضغط الملف بالكامل داخل مجلد عادي تملك صلاحية الكتابة فيه.
2. افتح Run ثم اضغط START.cmd مرتين.
3. يفتح الموقع في المتصفح على http://127.0.0.1:3120
4. اترك نافذة التشغيل مفتوحة؛ للإيقاف اضغط Ctrl+C.

لا تحتاج نسخة Run إلى تثبيت Node.js أو المكتبات؛ المتطلبات مرفقة.
الإنترنت مطلوب عند الاتصال بخدمة واتساب. أدخل بيانات اشتراك الشركة من الشاشة.

للمبرمج:
ابدأ من Source/README.md. Source يحتوي كود التطبيق القابل للتعديل والدمج.
Run يحتوي الواجهة المبنية والسيرفر المجمّع ومشغّل Node.js ومكتبة SQLite.
هذا تشغيل ويب محلي؛ ربطه بصلاحيات النظام والاستضافة موضح في شرح السورس.
نسخة التشغيل معدة لويندوز x64؛ للأنظمة الأخرى استخدم السورس وابنِه على الجهاز المستهدف.

لإعادة تجهيز Run بعد تعديل السورس، باستخدام Node.js على Windows x64:
داخل Source: pnpm install --frozen-lockfile
داخل Source: pnpm build
داخل Source: node ../Run/build-runtime.mjs
أوقف نسخة Run قبل إعادة البناء. العملية تحتاج الإنترنت لجلب ترخيص Node.js المطابق.
لا تستبدل node.exe أو better_sqlite3.node منفردًا؛ يعاد تجهيزهما معًا.

الحزمة المرسلة خالية من بيانات حساب أو رسائل أو مفاتيح تشفير مستخدمة.
عند تشغيلها ينشأ Run/data لحفظ إعدادات الشركة وسجلها. لا ترسل هذا المجلد
أو أي ملف .env عند إعادة مشاركة الحزمة بعد استخدامها.

قبول طلب الإرسال من الخدمة لا يعني تأكيد وصول الرسالة إلى المستلم.
اختبر الربط والرسالة والمرفق بحساب اختبار قبل اعتمادها داخل نظام الشركة.
